UUID v7 Time-Ordered (RFC 9562)

Millisecond timestamp prefix followed by random bits. Modern standard for database primary keys (Postgres, MySQL, Mongo) to eliminate index fragmentation.

Gregorian calendar 100-nanosecond timestamp with clock sequence and randomized 48-bit node identifier.
