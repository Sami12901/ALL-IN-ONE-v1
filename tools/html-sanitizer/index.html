Understanding HTML Sanitization & XSS Defense

Cross-Site Scripting (XSS)

XSS attacks inject malicious JavaScript into web applications viewed by other users. Attackers use tags like <script>, embedded vector triggers like <img onerror="...">, or disguised protocols like href="javascript:..." to hijack sessions and exfiltrate credentials.

Whitelist Filtering Principle

Rather than trying to blacklist known bad strings (which can be bypassed with obfuscation and character encodings), a robust sanitizer enforces strict whitelisting: only designated semantic tags and attributes are permitted, and all untrusted elements are pruned.

Sandboxed Iframes

The preview pane leverages the browser's native sandbox="" isolation. An empty sandbox flag strictly blocks script execution, form submission, popup windows, and top-level navigation, providing total containment.
