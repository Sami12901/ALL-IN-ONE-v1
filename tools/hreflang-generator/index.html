Crucial Search Engine Rules

  • Self-referencing tag: Every localized version MUST include an hreflang link to itself alongside the other variants.
  • Bidirectional Return Links: If page A links to page B via hreflang, page B MUST link back to page A with reciprocal tags. Otherwise, Google disregards both annotations.
  • Absolute URLs only: Never use relative URLs like /es/page.html. Full protocols (e.g. https://...) are mandatory.
  • x-default fallback: Use x-default for generic country-selector landing pages or language splash screens.
