Key Features & Technical Capabilities

100% Client-Side Privacy

All video frame extraction, inpainting, and video encoding occur entirely inside your browser memory without any cloud processing.

Alexandru Telea Fast Marching

Propagates image boundary gradients along level lines (isophotes) into text strokes, maintaining sharp edges and seamless continuity.

Temporal Smoothing

EMA filtering blends successive frames to prevent subtitle flicker, with scene cut detection to guard against transition artifacts.

Audio Preservation

Original audio streams and dialogue tracks are captured via Web Audio API and multiplexed into the clean output WebM video.

Frequently Asked Questions (FAQ)

Can this tool remove burned-in subtitles permanently?

Yes. The tool reconstructs the underlying image pixels behind burned-in text using advanced AI inpainting algorithms, producing a clean video file.

Does it work with moving lower thirds or scrolling tickers?

Yes. You can select the entire lower third or ticker band with the Bounding Box to erase the text across all video frames.

Will my original audio and dialog be preserved?

Yes. The tool uses Web Audio API node caching to extract and preserve original audio tracks in perfect synchronization with the clean video.

What is the recommended FPS setting?

For standard web videos, 30 FPS is recommended. For movies and cinema files, select 24 FPS for maximum speed and fidelity.
