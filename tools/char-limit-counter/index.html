Social Media Character Limit Best Practices

Twitter / X (280 chars)

Tweets with 70–100 characters often experience the highest engagement. URLs always consume 23 characters regardless of length due to the t.co shortener.

Instagram (150 bio / 2,200 caption)

While captions allow up to 2,200 characters, only the first 125 characters appear before the "...more" truncation button. Place hooks in the first line.

LinkedIn (3,000 chars)

The first 140–210 characters show in the feed before the "see more" cutoff. Aim for 800–1,500 characters for thought leadership articles.

SMS Messages (160 GSM-7)

Standard SMS messages are capped at 160 characters. Adding emojis or unicode changes the encoding to UCS-2, dropping the limit per segment to 70 characters.
