Key Features & Technical Capabilities

100% Client-Side Privacy

Your video is processed strictly in your local browser memory using Canvas 2D and Web Audio API without uploading to external servers.

Semi-Transparent Detection

Heuristic gradient and contrast thresholding detects faint, semi-transparent watermark stamps across light and dark video backgrounds.

Temporal EMA Blending

Inter-frame exponential moving average smoothing eliminates frame-to-frame flicker and preserves video temporal consistency.

Lossless Audio Preservation

Original audio channels, music, and voiceover tracks are piped into the destination stream with perfect synchronization.

Frequently Asked Questions (FAQ)

Can it remove moving or static watermarks?

Stationary watermarks and corner stamps are removed with maximum fidelity. You can adjust the bounding box or use brush mode to target the exact watermark footprint.

Will removing the watermark blur the whole video?

No. Only the pixels inside the selected watermark boundary are reconstructed. All surrounding video pixels remain 100% untouched and sharp.

Is there any file size or duration limit?

Since processing happens 100% locally on your computer, there are no artificial file size or duration limits imposed by our servers.

Can I cancel the processing if needed?

Yes. The progress modal features a functional "Cancel Processing" button that halts video processing immediately and restores the studio.
