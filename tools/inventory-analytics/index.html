ABC Inventory Management Directives

Class A Strategy

High value items representing 80% of revenue. Enact tight daily cycle counts, automated supplier EDI triggers, and zero excess buffer.

Class B Strategy

Moderate value items (15%). Review weekly. Maintain standard buffer stock and negotiate periodic bi-weekly supplier restocks.

Class C Strategy

Low value tail (5%). Order in bulk to obtain volume shipping breaks. Minimize administrative overhead with simple two-bin reorder rules.
